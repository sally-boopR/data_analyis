# 가상기업 3개사 5개년 매출 데이터 심층 분석 보고서 및 대시보드 매뉴얼

본 프로젝트는 `가상기업 3개 5개년매출데이터 (2).xlsx` 파일에 수록된 60개월(2021.01 ~ 2025.12) 동안의 3개 기업(한빛테크, 미래솔루션, 새봄산업) 월별 매출 데이터를 바탕으로, **20가지 고급 통계·시계열·경영분석 기법**을 전수 적용하여 개발된 **100% 로컬 프론트엔드 데이터 분석 대시보드**입니다.

---

## 🔒 100% 로컬 구동 & 보안 보장 (Zero External Data Leakage)
- **노 빌드(No-Build) 아키텍처**: Node.js, Webpack, Vite 등의 복잡한 빌드 도구 없이 `index.html`을 더블클릭하거나 `대시보드열기.bat`를 실행하면 즉시 동작합니다.
- **외부 전송 0%**: 모든 데이터 연산, 시계열 필터링, 차트 렌더링이 브라우저 내부 메모리(Client-side)에서만 수행되며, 외부 서버 통신이나 텔레메트리가 전혀 없습니다.
- **오프라인 라이브러리 탑재**: Chart.js 라이브러리(`chart.umd.min.js`, 208KB)가 로컬 디렉토리에 번들링되어 있어 인터넷 연결이 차단된 폐쇄망 환경에서도 완전하게 구동됩니다.

## 📊 20대 분석 기법 체계 및 핵심 분석 결과 해설

### [영역 1: 기초 통계 및 종합 성과 평가]
1. **기술통계 및 5수치 분포 요약 (Descriptive Statistics & 5-Number Summary)**
   - **수식**: 평균($\mu$), 표준편차($\sigma$), 중앙값($Q_2$), IQR($Q_3 - Q_1$), 왜도($Skewness$)
   - **분석 결과**: 
     - **한빛테크**: 평균 12.56억, 최저 7.69억, 최고 18.27억, 표준편차 2.76, 왜도 +0.36 (지속적인 매출 레벨업에 따른 우측 꼬리형 분포).
     - **미래솔루션**: 평균 8.50억, 최저 6.22억, 최고 11.80억, 표준편차 1.30, 정규분포에 가장 근접한 대칭형 분포.
     - **새봄산업**: 평균 9.06억, 최저 7.61억, 최고 11.33억, 표준편차 0.96 (표준편차가 가장 작으나 이는 성장이 멈춘 '정체 상태'를 뜻함).

2. **5개년 연평균 복합 성장률 (CAGR) 및 YoY 성장 모멘텀**
   - **수식**: $CAGR = (V_{2025} / V_{2021})^{1/4} - 1$
   - **분석 결과**:
     - **한빛테크**: **+15.20%** (연도별 YoY: +15.0% → +15.5% → +16.0% → +14.2%로 5개년 연속 두 자릿수 고속 성장).
     - **미래솔루션**: **+8.74%** (연도별 YoY: +9.2% → +8.4% → +10.0% → +7.3%로 완만한 우상향).
     - **새봄산업**: **-2.35%** (연도별 YoY: -2.4% → -1.5% → -3.2% → -2.3%로 4년 연속 역성장).

3. **매출 변동성 및 샤프 유사 안정성 지수 (Risk-Return Efficiency)**
   - **수식**: 변동계수 $CV = \sigma / \mu$, 효율지표 = $CAGR / CV$
   - **분석 결과**:
     - 한빛테크는 CV가 21.96%로 가장 높으나, 하방 위험이 아닌 급격한 우상향 성장에 기인한 '좋은 변동성'입니다. 위험 대비 성장 효율 지수는 **0.69**로 압도적 1위를 기록했습니다.
     - 새봄산업은 CV가 10.60%로 가장 낮지만 마이너스 성장으로 인해 효율 지수가 **-0.22**로 열위합니다.

4. **누적 매출(Cumulative Revenue) 궤적 및 골든크로스 마일스톤**
   - **수식**: $Cumulative_t = \sum_{i=1}^t Sales_i$
   - **분석 결과**:
     - 5개년 누적 총매출: **한빛테크 753.5억원(41.7%) > 새봄산업 543.7억원(30.1%) > 미래솔루션 510.3억원(28.2%)**.
     - 2021년 초 새봄산업이 누적 1위였으나, **2022년 3분기(20개월차)**에 한빛테크가 새봄산업을 누적 역전하는 역사적 골든크로스를 달성했습니다.

### [영역 2: 추세 평활화 및 시계열 분해]
5. **다중 이동평균(SMA 3M / 6M / 12M) 필터링**
   - **수식**: $SMA_k(t) = \frac{1}{k}\sum_{i=0}^{k-1} X_{t-i}$
   - **분석 결과**: SMA 12M(12개월 이동평균)은 월별 계절 요동을 완전히 제거합니다. 한빛테크의 SMA 12M선은 2021년 9.26억에서 2025년 16.31억으로 단 한 번의 꺾임 없는 단조 증가(Monotonic Increase)를 증명합니다.

6. **고전적 시계열 가법 분해 (Additive Decomposition)**
   - **수식**: $Y_t = Trend_t + Seasonal_t + Residual_t$
   - **분석 결과**: 한빛테크는 강력한 우상향 추세 위에 봄철 피크(+1.15억)와 가을철 저점(-1.68억)의 계절 진폭이 명확히 분리되며, 잔차(불규칙 요인)의 비중이 4% 미만으로 모형의 설명력이 극히 뛰어납니다.

7. **지수이동평균(EMA 6M vs 12M) 및 모멘텀 스프레드**
   - **수식**: $\alpha = 2 / (N+1)$, $Spread = EMA_{6} - EMA_{12}$
   - **분석 결과**: 한빛테크는 매년 1~5월 구간마다 단기선이 장기선을 강하게 상회하는 확장 국면(Spread > +0.8억)을 나타냅니다.

8. **호드릭-프레스콧(HP) 필터 기반 경기 순환 변동(Cyclical Gap)**
   - **수식**: $\min \sum (y_t - g_t)^2 + \lambda \sum (\Delta^2 g_t)^2$ ($\lambda = 14,400$)
   - **분석 결과**: 장기 잠재 성장선 대비 단기 경기 갭을 추출한 결과, 3개사 모두 약 12~14개월 주기의 미니 경기 사이클을 가지며 한빛테크는 2023년 및 2025년 상반기에 대규모 호황 갭(+2.0억원 안팎)을 형성했습니다.

### [영역 3: 계절성 및 주기성 분석]
9. **12개월 월별 계절 지수 (Seasonal Index, Base 100)**
   - **수식**: $SI_m = (\bar{X}_m / \bar{X}_{all}) \times 100$
   - **분석 결과**:
     - **한빛테크**: 3월(108.9%), 4월(109.5%), 5월(109.4%) 최고, 10월(86.4%) 최저 (봄철 성수기 피크).
     - **미래솔루션**: 12월(116.8%), 11월(109.3%), 1월(102.8%) 최고, 8월(86.4%) 최저 (연말 예산집행 피크).
     - **새봄산업**: 12월(119.4%), 11월(112.9%), 1월(110.0%) 최고, 8월(88.0%) 최저 (동절기 집중 피크).

10. **연도 × 월 매트릭스 계절 히트맵 (Seasonality Matrix Heatmap)**
    - **분석 결과**: 5개년 60개 셀의 색상 강도를 통해 한빛테크의 전반적 레벨업 추세와 매년 반복되는 봄철 고밀도 영역을 직관적으로 확인 가능합니다.

11. **분기별 실적 분할 및 전년 동기 대비(YoY) 워터폴**
    - **분석 결과**: 새봄산업은 4분기 비중(31.2%)이 비정상적으로 높아 3분기(19.8%) 비수기 운영자금 압박 위험이 존재합니다. 한빛테크는 4개 분기 모두 고른 기여도를 유지하고 있습니다.

12. **자기상관함수 (ACF: Autocorrelation Function) 지연 주기성 검정**
    - **수식**: 95% 유의성 임계선 = $\pm 1.96 / \sqrt{60} = \pm 0.253$
    - **분석 결과**: Lag 1의 관성(0.68~0.87)과 Lag 12의 강한 스파이크(0.58~0.73)가 임계선을 크게 초과하여 12개월 주기의 강력한 연간 계절성이 통계적으로 엄밀히 입증되었습니다.

### [영역 4: 기업 간 상호 비교 및 시장 구조]
13. **피어슨 및 스피어만 상관계수 행렬 (Correlation Matrix)**
    - **분석 결과**:
      - **한빛테크 ↔ 미래솔루션**: **r = +0.871** (강력한 정(+)의 상관, 전체 시장 파이 확대에 따른 동반 성장).
      - **한빛테크 ↔ 새봄산업**: **r = -0.226** (음(-)의 상관, 한빛테크가 새봄산업의 점유율을 잠식하는 대체 관계).
      - **미래솔루션 ↔ 새봄산업**: r = +0.236 (약한 양의 상관, 연말 동절기 계절성 공유).

14. **동적 시장 점유율 (SOM) 전이 및 구조 변화**
    - **분석 결과**:
      - 2021년: 새봄산업(36.7%) > 한빛테크(35.8%) > 미래솔루션(27.5%)
      - 2025년: **한빛테크(46.8%)** > 미래솔루션(28.5%) > 새봄산업(24.7%)
      - 한빛테크가 시장 점유율을 11.0%p 확대하며 절대 1강으로 올라섰습니다.

15. **허핀달-허쉬만 지수 (HHI) 시장 집중도 추이**
    - **수식**: $HHI = \sum_{i=1}^3 (s_i)^2$
    - **분석 결과**: 2021년 평균 3,421pt에서 2025년 3,680pt로 259pt 상승하여 과점 시장(>2,500pt) 내에서 1강 체제가 더욱 굳어지고 있음을 보여줍니다.

16. **기준 시점 상대 지수화 (Indexed Growth, 2021.01 = 100)**
    - **분석 결과**: 2025년 12월 기준 한빛테크는 지수 **205.0p**(2.05배 성장), 미래솔루션은 **166.2p**(1.66배 성장), 새봄산업은 **100.0p**(5년 전 원점 제자리걸음)를 기록했습니다.

### [영역 5: 리스크 및 이상치 탐지]
17. **Z-Score 기반 통계적 이상치(Anomaly) 자동 감지**
    - **수식**: $Z_t = (X_t - \mu) / \sigma$, $|Z| \ge 1.96$
    - **분석 결과**: 한빛테크의 2025년 3월(18.27억, Z=+2.07) 및 4월(18.14억, Z=+2.02)에 상방 이상치가 포착되었으며, 이는 대규모 신제품 런칭 효과로 분석됩니다.

18. **최대 낙폭 (MDD: Maximum Drawdown) 언더워터 분석**
    - **수식**: $DD_t = (X_t - Peak_t) / Peak_t \times 100\%$
    - **분석 결과**: 한빛테크는 비수기 MDD가 -27.3%에 달하나 매년 4~6개월 내 전고점을 갱신한 반면, 새봄산업은 2021년 12월 최고점(11.33억) 이후 현재까지 -32.8%의 지속적 침체 상태에 갇혀 있습니다.
